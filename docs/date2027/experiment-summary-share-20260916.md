## 历史：原主实验失败原因

- Directed stimulus：ALU 请求超时；CAN、I2C 推理预算耗尽；SPI 输出截断；GPIO 响应读取中断；ETHMAC 证据工具预算耗尽。
- Directed SVA：ETHMAC、I2C、GPIO 推理预算耗尽；UE_SPI 测试平台编译失败。
- HAVEN：CAN、UE_UART 生成序列轮询等待超时。
- RVProbe：ALU、UE_SPI 推理预算耗尽；UE_UART 响应读取中断；AXIL_RAM 辅助 Yosys 路径错误。

## 结论与论文使用口径

- 每设计取最新一次结果，RVProbe 16 项均有正常结束记录，平均综合覆盖率 95.13%。这是混合配置快照，不是统一配置的完整重跑，也不是所有 intent 均满足。
- 原主实验 RVProbe 比 HAVEN 平均覆盖率高 0.85 个百分点，已报告 token 为其约 1.82 倍；目前不能声称总体 token 更省。
- 主实验及这 5 次重跑累计已报告 25,160,295 tokens，不包含更早开发调试费用，且缺失 usage 未擅自算零。
- 建议论文主表保留原 64 项，将大预算及框架修复重跑单列为补充实验，不能只替换失败项而隐去旧结果和费用。
- 重跑同时存在预算、部分框架/提示词及 effort 变化，模型输出也不同，不能将覆盖率变化全部归因于某一项修复；单次结果不支持普遍鲁棒性或统计显著性结论。
