## 原始实验记录（受污染）

2026-09-05 完成 20 次真实模型调用、19 个有效样本的 Scala/JasperGold 检查与 VCS/URG 回放。
以下只保存受污染实验中实际观测到的差异和失败，不再据此主张框架 RAG 有收益。

## 对照设置

- 模型：`deepseek-v4-flash-vision-exp`，temperature 0.3，每组 5 次，每次只请求一次，不修复、不重试。
- 两组使用同一版 prompt 和两段 Scala 声明输出约定，唯一干预是是否注入检索内容；不是旧版完整 Scala prompt 对比新版 prompt。
- 首轮输入为 13 条历史残余行；末轮输入为历史首轮序列执行后剩余的 2 行。两轮是固定任务，不是各新样本的自适应延续。
- 模型调用以 2 个 worker 按记录的打乱顺序执行；Scala/JasperGold 串行执行。
- 19 个有效样本在同一个新 VCS build 中回放，统一 seed 1，每次使用独立覆盖数据库；两轮都有同 build 的基线。
- RTL、语料和每组 prompt 的哈希已核对。实际基线残余分别为 13 行和 2 行，与模型输入一致。

## 结果

token 和生成时间均为每请求均值，包含格式失败请求；覆盖和求解只统计有效样本，分母明确列出。

| 固定任务 | 模式 | 一次通过 | 平均 token | 平均生成时间 | 新闭合目标行 |
|---|---|---:|---:|---:|---:|
| 首轮 | 无 RAG | 5/5 | 51,421 | 423.13 秒 | 9–11，均值 10.6 |
| 首轮 | RAG | 5/5 | 28,792 | 222.01 秒 | 11，5/5 均补齐可达缺口 |
| 末轮 | 无 RAG | 5/5 | 31,019 | 258.47 秒 | 0，5 次回放 |
| 末轮 | RAG | 4/5 | 10,857 | 82.74 秒 | 0，4 次回放 |

合计每组 10 次请求：RAG 使用 198,248 token，无 RAG 使用 412,201 token，减少 **51.9%**。
每请求平均模型生成时间减少 **55.3%**，不是端到端墙钟时间的加速比例。
首轮 token 减少 44.0%、生成时间减少 47.5%；末轮分别减少 65.0%、68.0%。
只看末轮 RAG 的 4 个有效响应，其均值仍为 12,018 token、92.75 秒。

首轮 RAG 的平均候选数为 4，无 RAG 为 4.4；候选 JasperGold 调用计时分别平均 26.54 秒、29.21 秒。
末轮无 RAG 每次生成 1–2 个候选，平均求解 10.70 秒，均未闭合剩余目标行。
末轮 4 个有效 RAG 响应均不生成候选，而是提交两项证明请求，因此没有候选求解调用；仍有 harness 开销。

### 覆盖不能只看综合分

首轮全部可达缺口闭合次数为 RAG 5/5、无 RAG 4/5。完全闭合后行覆盖为 177/179，即 98.88%。
无 RAG 的 `round1-off-2` 仍遗漏可达的 475、476 行，另有结构不可达的 336、401 行。
该样本确实提出了 reserved opcode 10，且求解成功；不能把此次漏覆盖简单归结为非法输入。
它将 reserved case 放在 FP2INT NaN 之前，当前驱动的握手/顺序影响未做独立因果实验。

首轮 DUT 四指标综合分均值为 RAG 94.61、无 RAG 94.50。
末轮则为 RAG 94.73、无 RAG 95.00：无 RAG 的额外候选新增 2 个 condition bin 和 3 个 toggle bin，
但没有新增目标行或 branch bin。RAG 不是所有覆盖指标都更高。

### 格式与证明审计

- `round2-local-3` 缺少 `proofObligations` 的外层结尾括号，格式检查拒绝；保留原始回答和成本，没有补写、重试或计入回放成功。
- `round2-local-1` 的 `fp_active` / `fp_counter` 不变量正确，但文字误称其为 FP2INT 状态机；不能称所有解释完全无误。
- `round2-off-1` 错把 336 行的计数器默认分支解释成 opcode 默认分支。
- 独立重新运行现有 `prove_deadcode.tcl`：336、401 两项 cover 均得到 `unreachable`。日志还记录了假设无冲突、无死端，且 live 检查可达。
- 证明结论来自独立属性，在既有复位约定下成立；模型输出 `proofObligations` 本身不构成证明。

## 适用边界与产物

每组仅 5 次、仅一个仿真 seed；以上为描述性结果，不作统计显著性断言。
RAG 语料包含本 ALU 的历史操作数和不可达分析，测试的是项目记忆复用，而非纯写法提示收益。
