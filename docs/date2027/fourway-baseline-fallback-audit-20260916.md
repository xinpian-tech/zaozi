## 覆盖率统计规则（逐项复核版）

本版已逐项检查原四方法 64 个单元及新 RVProbe 16 个单元，共 80 个实验结果：

- 只采用成功接受并通过本方法仿真验收的新增激励对应的覆盖率；后续失败不抹去此前有效结果。
- 如果没有任何有效新增激励，则取固定 Stage-1 激励的 baseline 覆盖率，不计零、不使用失败候选的测量值。
- token、时间和尝试轮次保留全部失败开销；不以是否出现覆盖率增益判断激励是否有效。
- 80 个结果按上述规则重算后与上一版数值一致。新增 Stage-1 only 列及 `B` 标记，使回退来源明确。
- Stage-1 only 是仅运行既有初始激励、不开启 Stage-2 生成闭环；不是无激励仿真。16 设计平均 baseline 为 **69.72%**。

`B` 表示没有有效新增激励，覆盖率来自 baseline；它与失败标记 `×` 不同，正常停止但未产生有效新激励也可标 B。

## 新批次配置与失败说明

- 模型请求名：`deepseek-v4-flash-vision-exp`；reasoning_effort=`max`；每请求 max_tokens=393216（含推理与最终输出），超时 3600 秒。
- 固定 Stage-1、当前修复后的 RVProbe 框架；全新生成，不复用旧模型回复。HAVEN 未重跑、未改动。
- 3 个设计并发，每设计最多 3 轮，每 intent 最多 4 条 sequence。单个设计失败后继续其他设计。
- 本批实际起止（UTC）：2026-09-16T05:19:50.410+00:00 至 2026-09-16T09:06:49.100+00:00；含归档墙钟 3.78 小时。
- ETHMAC 第二轮失败：`task tool-call budget exhausted; batch entries count individually`。已执行 7 次批量搜索（44 项）、5 次批量读取（16 项）、1 次框架参考读取（1 项），合计 61/64 项；下一批请求超出剩余配额，尚未产出第二轮最终 LTL 就退出。
- ETHMAC 失败第二轮：8 次模型请求、1,016,519 tokens；该设计全程 2,243,995 tokens 全部保留，覆盖率采用第一轮有效值 90.7494%。这是工具预算耗尽，不是输出 token 截断。
- 16 个设计均已结束并归档：15 正常、1 失败。正常结束不等于全部 intent 可满足或所有 witness 都成功。

## 统计与论文口径

- 综合覆盖率为每设计有效 line/cond/toggle/branch/fsm 百分比均值；总体为 16 个设计等权平均。已核对新批次与原四方法基线 bins、覆盖率分母一致。
- 时间统一使用 Stage-2 arm 耗时，不含固定 Stage-1 生成费用；累计时间不是并发墙钟。此前进度消息中部分单项耗时为含基线初始化的 paired 总时间，本表已统一统计口径。
- 轮次为尝试的覆盖闭环轮次，不是模型 HTTP 请求数。ETHMAC 第二轮失败也计入尝试轮次。
- 新批次全部请求 usage 完整，10,989,224 tokens 为本次全部 16 设计的实际报告用量，包含 ETHMAC 失败费用；不含以前独立重跑及开发调试费用。
- 对比 HAVEN：新 RVProbe 平均覆盖率高约 2.50 个百分点，tokens 约为 2.64 倍。大预算未带来总体 token 节省。
- 新增列同时改变了框架与预算，且模型采样输出不同，应作为修复＋大预算补充实验，不将差异全部归因于单个因素；本表不替代此前混合配置的最新结果快照。
